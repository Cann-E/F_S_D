Use semantic HTML and ensure the structure is accessible. ✅ User Stories: You should have an h1 element with the text Mr. Whiskers' Blog. You should have three section elements immediately after the h1 element. You should have an h2 element with the text Photo Gallery within the first section. You should have at least two figure elements inside the first section. Each figure should contain an img element with an appropriate alt attribute. Each figure should include a figcaption element that describes the photo. You should have an h2 element with the text Blog Posts within the second section. You should have at least two article elements inside the second section. Each article should include an h3 element with the blog post title. Each article should include at least two p elements with content. You should have an h2 element with the text Contact within the third section. You should have an address element inside the third section. The address should include a phone number using a tel: link and an email using a mailto: link.
