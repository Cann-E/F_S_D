🎯 Objective: Design a recipe page with a feedback form. Display a recipe’s ingredients, steps, image, and collect user opinions. ✅ User Stories: You should have an h1 element with the text Chocolate Chip Cookies. You should have three section elements immediately after the h1 element. You should have an h2 element with the text Ingredients within the first section. You should have a ul element with at least four li ingredients inside the first section. You should have an h2 element with the text Instructions inside the same section. You should have an ol element with at least three li steps below the instructions heading. You should have an h2 element with the text See the Cookies within the second section. You should have a figure element that includes an img with an appropriate alt attribute. The figure should include a figcaption that describes the image. You should have an h2 element with the text Feedback Form within the third section. You should have a form element within the third section. You should have an input with an id and name of user-name and a label associated with it. You should have a select element with a label for rating the recipe. You should have a textarea element with a label for user comments. At least two input elements should be required and have an aria-required attribute set to true.
