🎯 Objective: Create a web page that shows upcoming and past events. Add a form that lets users RSVP for events. ✅ User Stories: You should have an h1 element with the text Event Hub. You should have three section elements immediately after the h1 element. You should have an h2 element with the text Upcoming Events within the first section. You should have at least one article inside the first section. The article should include an h3 with the event title. The article should include a p with a short event description. The article should include an img element with an appropriate alt attribute. You should have an h2 element with the text Past Events within the second section. You should have at least one article inside the second section with the same structure as above. You should have an h2 element with the text RSVP Form within the third section. You should have a form element within the third section. You should have an input with an id and name of full-name and a label associated with it. You should have at least two radio input elements for selecting event type with labels. You should have a checkbox input element with a label for agreeing to terms. At least two of your input elements should be required and have an aria-required attribute set to true.
